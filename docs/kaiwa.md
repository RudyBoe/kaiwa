# Kaiwa index

The main list of all kaiwa (dialogues and stories) in this repo. Each kaiwa is
one file in `library/`, in the strict kaiwa/1 format
([kaiwa-format.md](kaiwa-format.md)), and appears in the app at
**https://rudyboe.github.io/kaiwa/**. The files themselves are the source;
this page only lists them, together with ideas and the change log.

The claude.ai project *Japan Slow Travel* keeps only a pointer to this file.

## How to add a kaiwa

1. Write it with the `kaiwa` skill at the right Minna level (`level.minna_max`;
   40–50 % of the grammar from the last five lessons).
2. Save it as `library/<id>.kaiwa.json` and add the file name to
   `library/index.json`.
3. Run `python3 tools/validate_kaiwa.py library/*.kaiwa.json`,
   `node tools/check.mjs` and `node tools/index-md.mjs` (rebuilds the table
   below), add a change-log line, then commit and push.

In the app, a kaiwa only shows up once Settings › *My Minna lesson* reaches
its level (or with the *Up to* filter turned off).
